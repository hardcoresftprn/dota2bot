# Мета по пяти позициям

Функция работает в Cloudflare-версии бота.

## Команды

- `/meta` — три героя на каждую из пяти позиций, все ранги.
- `/meta 1` … `/meta 5` — пять героев для одной позиции.
- `/meta 2 legend` — мид на Легенде; `/meta immortal` — пять позиций на Титане.
- Под ответом — кнопки позиций и выбора ранга. Они обновляют одно сообщение.

Позиции: 1 — керри, 2 — мид, 3 — оффлейн, 4 — поддержка, 5 — полная поддержка.
Ранги: `all`, `herald`, `guardian`, `crusader`, `archon`, `legend`, `ancient`,
`divine`, `immortal`. Для примеров удобнее использовать эти английские ключи;
названия на русском в одно слово тоже распознаются.

## Источник и свежесть

Используется публичный JSON-маршрут сайта **StatsDota**, который использует и сам
сайт: `https://statsdota.com/api/meta-board?rank=all&position=carry&lang=en&v=board`.
Для каждого ранга и каждой позиции запрашивается отдельный срез. Общий винрейт
героя из OpenDota не выдаётся за винрейт по позиции.

[Пример страницы источника](https://statsdota.com/en/meta/all/carry) ·
[Методика расчёта](https://statsdota.com/en/meta/methodology).

Бот использует рейтинг StatsDota, а не сортирует только по сырому винрейту.
Источник учитывает победы с поправкой на выборку, а также популярность пиков и
банов; редкие позиции и слишком маленькие выборки исключает из основного рейтинга.
Источник может расширять малую выборку ранга — бот явно отмечает такой случай.

В ответе есть патч, период, время данных, винрейт; в подробном списке —
популярность, число матчей и оценка источника из 100. План игры для позиции —
общая подсказка, а не вывод о конкретном герое или обещание победы.

Кеш в D1 обновляется по запросу раз в час для каждого среза. Блокировка на
30 секунд защищает от параллельных одинаковых запросов. При сбое источника
используется сохранённая выборка с явной отметкой устаревания и короткой паузой
перед повтором. Кеш старше недели не показывается. Если патч источника старее
последнего патча, известного боту, это отмечается отдельно. Старое время данных
и слишком старый период также не маскируются временем нового HTTP-запроса.

Мета не добавляется в автоматическую рассылку патчей: пользователь запрашивает
её командой или кнопками. Изменения подписок и очереди патчей для неё не нужны.

## Обновление Telegram

После обновления кода запустите:

```sh
cd cloudflare
node setup-telegram.js --url https://dota2bot.sdsbtw.workers.dev
```

Скрипт обновит меню и включит `callback_query` в webhook для кнопок.
Повторно загружать runtime Secrets при этом не требуется.

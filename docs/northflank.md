# Бесплатный запуск на Northflank

**Прежний вариант. По выбору владельца проект переведён на Cloudflare после
ошибок регистрации Northflank. Используйте [инструкцию Cloudflare](cloudflare.md).**

На 6 ноября 2026 года [Northflank Sandbox](https://northflank.com/pricing)
заявляет работу без засыпания, без банковской карты и до $20 бесплатных ресурсов
в месяц. Нужен аккаунт Northflank и GitHub/GitLab/Bitbucket для исходного кода.
Здесь используются один небольшой сервис и одна небольшая PostgreSQL.

## 1. Подготовить Telegram

Создайте бота через [@BotFather](https://t.me/BotFather) → `/newbot`.
Сохраните токен: он понадобится только в секретах сервиса.

## 2. Загрузить проект в GitHub

Создайте **приватный** репозиторий, например `dota-patch-watch`.
Загрузите файлы проекта с сохранением папок `dotabot`, `docs`, `tests`.
В корне должны оказаться `Dockerfile`, `requirements.txt` и `README.md`.

Не загружайте `.env`, `.venv`, `data` и `__pycache__`. Файл `.env.example` безопасен:
в нём только шаблон. Если используете Git, `.gitignore` уже исключает секреты.

## 3. Создать проект и PostgreSQL

1. Зарегистрируйтесь на [Northflank](https://app.northflank.com/) и выберите
   **Sandbox / Free**, без перехода на платный план.
2. Создайте проект `dota-bot` в доступном регионе.
3. В проекте создайте addon **PostgreSQL**. Выберите минимальный бесплатный
   размер, одну реплику и минимальное доступное хранилище. Сверьте оценку ресурсов
   с бесплатным лимитом. Не включайте платные дополнительные функции.
4. После запуска базы откройте её **Connection details**. Нужна внутренняя строка
   подключения PostgreSQL с именем базы, пользователем и паролем.

База должна находиться в том же проекте. Публично открывать порт PostgreSQL не нужно.
Инструкция провайдера: [подключение к базе](https://northflank.com/docs/v1/application/databases-and-persistence/access-a-database).

## 4. Создать сервис бота

1. Создайте **Combined service** (сборка и запуск из Git-репозитория).
2. Подключите репозиторий, выберите рабочую ветку.
3. Способ сборки: **Dockerfile**, путь `/Dockerfile`, build context — корень.
4. Выберите минимальный бесплатный размер, **одну реплику**. У бота нет требований
   к входящему трафику: он использует Telegram long polling.
5. В **Runtime variables / Secrets** добавьте:

   | Ключ | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | Токен BotFather |
   | `DATABASE_URL` | Внутренняя строка подключения PostgreSQL из шага 3 |
   | `CHECK_INTERVAL_SECONDS` | `600` |
   | `PORT` | `8080` |

   По возможности используйте linked secret базы для `DATABASE_URL`.
   Ключи нужны **во время работы**, не только при сборке.

6. `OPENAI_API_KEY` оставьте пустым для режима без оплаты AI.
7. Если интерфейс предлагает проверку работоспособности, настройте HTTP
   `/healthz` на порту `8080`. Порт можно оставить приватным: публичный домен боту
   не требуется.
8. Выберите обновление с остановкой старой реплики перед запуском новой
   (`recreate` / без перекрытия реплик), если этот параметр доступен.
9. Проверьте, что сервис и база помещаются в бесплатные ресурсы, и запустите deploy.

## 5. Проверить

- В логах должно появиться `Бот @имя запущен`.
- Откройте бота в Telegram и отправьте `/start`.
- Через минуту проверьте `/status`: нужны успешные проверки Valve и Steam.
- `/latest` покажет сохранённый разбор последнего патча. Старые патчи автоматически
  не рассылаются — бот ждёт новых публикаций.
- Друзья нажимают Start в личке или администратор подписывает общий чат командой
  `/start@имя_бота`. Для надёжной проверки администраторов назначьте бота
  администратором группы без лишних разрешений.

## Обновления и сохранность

Подписки, курсоры, история и очередь отправок хранятся в PostgreSQL. Пересборка
контейнера их не удаляет. Не удаляйте addon базы. Локальные файлы контейнера
Northflank не сохраняются при перезапуске, поэтому **не используйте SQLite** на
этом варианте хостинга.

Не запускайте одновременно локальный экземпляр и сервер с одним токеном.
Если появляется Telegram 409, остановите лишний процесс. Если сервис не стартует
из-за блокировки базы при обновлении, дождитесь остановки старой реплики и
повторите deploy.

Бесплатные тарифы могут меняться. Если в вашем аккаунте нет бесплатной базы или
бесплатного сервиса, не включайте оплату автоматически: используйте локальный
Docker-вариант, пока не выбран другой хостинг.

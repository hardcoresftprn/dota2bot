# Бесплатный запуск на Cloudflare Workers + D1

Текущий вариант размещения. Не требует постоянно включённого компьютера,
отдельного VPS, Docker или банковской карты на Workers Free.
Northflank для этого запуска больше не используется.

На 6 ноября 2026 года [Workers Free](https://www.cloudflare.com/products/workers/)
включает 100 000 запросов в сутки; [D1 Free](https://developers.cloudflare.com/d1/platform/pricing/)
— 5 млн прочитанных строк, 100 000 записанных строк в сутки и 5 ГБ суммарного
хранилища. У [бесплатного Worker](https://developers.cloudflare.com/workers/platform/limits/)
есть лимит CPU 10 мс и 50 внешних запросов/запросов к сервисам за вызов.
Поэтому бот обрабатывает обновления небольшими порциями.

## Как работает

- Каждые 5 минут запускается короткая задача: она чередует Valve и Steam,
  проверяя каждый источник раз в 10 минут.
- Команды Telegram приходят через webhook и обрабатываются сразу, независимо от
  расписания. Публичный URL защищён случайным секретом в заголовке Telegram.
- История, подписки и очередь хранятся в D1. Один патч с двух официальных
  источников получает один ID и не рассылается заново.
- При первом запуске архив не рассылается; последний патч доступен через `/latest`.
- Каждый запуск рассылает до четырёх сообщений в разные чаты. Если подписчиков
  больше, очередь продолжит отправляться через 5 минут. После долгого простоя
  история новостей догружается постепенно, по одной странице за запуск.
- Базовый режим бесплатен: конкретные русские изменения Valve плюс осторожная
  оценка влияния. Для неструктурированных англоязычных новостей — тема и ссылка.
  OpenAI API необязателен и оплачивается отдельно.

## Подготовка

1. Зарегистрируйтесь на [Cloudflare](https://dash.cloudflare.com/sign-up),
   подтвердите email, если Cloudflare просит. Домен покупать/подключать не нужно.
2. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) → `/newbot`.
   В корневом `.env` проекта заполните `TELEGRAM_BOT_TOKEN`.
3. Нужен Node.js 22+; использована версия Node.js 24. Работайте в папке `cloudflare`:

```sh
cd cloudflare
npm ci
npx wrangler login
```

Официальный Wrangler откроет авторизацию Cloudflare. Вход и выдачу доступа
подтверждает владелец аккаунта. Если браузер не открывается, используйте
`npx wrangler login --browser=false` и откройте выданную ссылку сами.

## Создать базу

```sh
npx wrangler d1 create dota-patch-watch
```

В выводе будет `database_id`. Впишите его вместо нулевого ID в `wrangler.jsonc`,
в объекте `d1_databases`. Не создавайте повторную базу при каждом обновлении.

```sh
npm run db:remote
```

Эта команда применяет `schema.sql`; она не удаляет существующие данные.

## Разместить и подключить Telegram

```sh
npm run deploy
```

Скопируйте выданный адрес `https://dota-patch-watch.ВАШ-ПОДДОМЕН.workers.dev`.
Теперь загрузите секреты и подключите webhook:

```sh
node setup-telegram.js --url https://dota-patch-watch.ВАШ-ПОДДОМЕН.workers.dev --upload-secrets
```

Скрипт читает токен из `../.env`, генерирует секрет webhook, загружает их в
Cloudflare Secrets, настраивает меню команд и webhook. Секреты передаются Wrangler
через stdin, а не аргументы командной строки. Локальный `.dev.vars` исключён из Git.
Не запускайте Python long polling для этого токена одновременно с webhook-версией.

Когда скрипт покажет ссылку `https://t.me/ИМЯ_БОТА`, откройте её и отправьте `/start`.
`/status` покажет успешные проверки в течение ближайших 10 минут.
Cron Trigger может распространяться по сети Cloudflare [до 15 минут](https://developers.cloudflare.com/workers/configuration/cron-triggers/).

Друзья подписываются через Start в личке или администратор подписывает общий чат
через `/start@ИМЯ_БОТА`. Для надёжной проверки прав группы назначьте бота её
администратором без ненужных разрешений на удаление сообщений и блокировки.

## GitHub

Первый запуск можно сделать с компьютера через Wrangler; GitHub для него не нужен.
Позже репозиторий можно связать с Workers Builds для автоматических обновлений.
Если подключаете весь этот репозиторий, задайте корень сборки `cloudflare`,
команду сборки оставьте пустой, deploy command — `npx wrangler deploy`.
Секреты настраиваются как runtime secrets и не должны попадать в репозиторий.

## Проверки и ограничения

```sh
npm test
npm run db:local
npx wrangler deploy --dry-run
npm run dev
```

При ошибке сети с неоднозначным результатом отправка получает статус `uncertain`
и не повторяется автоматически, чтобы избежать дубля. Разбор доступен через
`/latest`. Подтверждённый Telegram 429 ставится на повтор после `retry_after`.
Повторная публикация уже обработанного патча и редактура того же патча не вызывают
новую рассылку. У необычно оформленных новостей возможны ошибки классификации.

Free имеет жёсткие лимиты: при их исчерпании обработка может приостановиться.
Не включайте платный тариф для обычного использования с друзьями. Состояние
источников смотрите через `/status`; HTTP `/healthz` проверяет только доступность
обработчика. Если очень крупный патч превысит CPU-лимит, понадобится разбить его
обработку на дополнительные этапы или использовать локальную Python-версию.

- Код загружен в `https://github.com/hardcoresftprn/dota2bot`, ветка `main`.

  Сборка из GitHub завершилась успешно.

- Создана D1 `dota2bot`, применена схема и проверены таблицы с триггером очереди.

  Наличие значений в файлах, подготовленных к коммиту, проверено до push.
- Webhook подтверждён Telegram: `/telegram` на адресе Worker. Запрос с секретом
  отвечает 200, без секрета — 403; ошибок доставки Telegram не сообщает.

  В D1 сохранён один активный подписчик.
